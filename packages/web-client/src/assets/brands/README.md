# Official logos

Services whose logo is not in the bundled icon set (Canva, Gamma, Microsoft 365, Slack, Microsoft Teams, Feishu,
Twilio) show their initials on a coloured tile. To show the real logo, drop the file the company publishes for
integration partners into this folder, named after the key below. SVG is best, PNG works too.

| File | Service |
| --- | --- |
| `canva.svg` | Canva |
| `gamma.svg` | Gamma |
| `microsoft-365.svg` | Microsoft 365 |
| `teams.svg` | Microsoft Teams |
| `slack.svg` | Slack |
| `feishu.svg` | Feishu |
| `twilio.svg` | Twilio |

Use the logo as supplied, unmodified, and follow the owner's brand guidelines: logos are trademarks of their owners
and are only used here to identify the service.
